# AES 加解密实验程序

本项目为《信息安全导论》课程提供一个基于 Python 的 AES 加解密实验示例，适用于北方工业大学信息安全专业学生理解对称加密算法的基本实现原理。

## 📌 项目简介

本实验项目使用 `pycryptodome` 库实现了 AES-128 加密与解密的基本流程，采用 CBC 模式，并配有自动填充与解密还原。

- **加密程序**：`aes_encrypt.py`
- **解密程序**：`aes_decrypt.py`
- **依赖环境**：详见 `requirements.txt`

## 🔐 加密流程说明

1. 输入明文；
2. 使用 128 位密钥（16 字节）；
3. 生成随机初始化向量（IV）；
4. 采用 CBC 模式加密，并使用 PKCS7 补齐；
5. 输出为 Base64 编码的密文（含 IV）。

## 🔓 解密流程说明

1. 接收 Base64 编码的密文；
2. 提取前 16 字节的 IV，后续为密文；
3. 使用相同密钥和 CBC 模式进行解密；
4. 去除填充，恢复原文。

## 🛠 使用方法

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行加密程序

```bash
python aes_encrypt.py
```

程序会输出加密后的密文（含 IV）。

### 3. 运行解密程序

```bash
python aes_decrypt.py
```

输入上一步的密文，即可恢复原文。

## ⚠ 注意事项

- 密钥需为 16 字节长度（超出将截断，不足将报错）。
- 加密解密使用 **相同的密钥** 才能成功还原。
- CBC 模式加密安全性较高，但仍需结合完整性校验（例如 HMAC）用于真实场景。

## 📚 拓展建议

本实验建议在掌握基本逻辑后，尝试：

- 修改为 ECB/GCM 模式并比较安全性；
- 加入图形化界面（如 PyQt5）；

- 配合密码强度检测模块使用。
